# Database Schema Changes: Username and Last_Login Columns

## Overview
This document summarizes the database changes made to add the missing `username` and `last_login` columns to the users table in both Java backend packages.

## Issue Identified
Both Java backend implementations (`ticket-tracker-java` and `java-ticket-tracker`) were missing two critical columns in the users table:
- **username** - Unique login identifier
- **last_login** - Timestamp of last successful authentication

These columns were already present in the Supabase (PostgreSQL) schema but were absent from the Oracle database schemas used by the Java packages.

**File:** `ticket-tracker-java/database/14-oracle-add-user-username-and-last-login.sql`

## Column Specifications

### username Column
- **Type:** VARCHAR2(100) in ticket-tracker-java, VARCHAR2(200) in java-ticket-tracker
- **Constraint:** UNIQUE (prevents duplicate usernames)
- **Nullable:** Yes (allows backward compatibility)
- **Default Value:** For existing users, populated with email prefix (part before @)
- **Purpose:** Unique identifier for user login (alternative to email)
- **Index:** Yes, for fast authentication queries

### last_login Column
- **Type:** TIMESTAMP (ticket-tracker-java) or TIMESTAMP WITH TIME ZONE (java-ticket-tracker)
- **Nullable:** Yes (NULL indicates user has never logged in)
- **Default Value:** NULL
- **Purpose:** Track last successful authentication timestamp
- **Index:** Yes, for user activity and session tracking queries
- **Updated:** On successful login via authentication logic

## Migration Strategy

### For Fresh Installations
Run the complete install script which now includes:
- Base schema with username and last_login columns
- Indexes for performance
- No additional migration needed

### For Existing Databases
Run the migration script:
```sql
-- For ticket-tracker-java
@14-oracle-add-user-username-and-last-login.sql
```

For java-ticket-tracker, manually add the columns:
```sql
ALTER TABLE users ADD (username VARCHAR2(200) UNIQUE);
ALTER TABLE users ADD (last_login TIMESTAMP WITH TIME ZONE);

-- Populate existing users
UPDATE users SET username = SUBSTR(email, 1, INSTR(email, '@') - 1) WHERE username IS NULL;

-- Add indexes
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_last_login ON users(last_login);
```
